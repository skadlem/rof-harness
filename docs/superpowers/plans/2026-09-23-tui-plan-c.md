# TUI Plan C (commands + credentials + live session) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `rof chat` becomes a usable live console: slash commands, provider login, and goal sessions you can watch and queue into — still with no orchestrator redesign.

**Architecture:** Commands parse to a closed `Action` enum the runner applies at goal boundaries (never mid-call). Credentials live in `~/.rof/credentials` (0600). Live mode polls the shared `TraceSink` (`events()` snapshot, index cursor) while the loop runs on a blocking task; composer text between goals starts the next goal on the same session. Full mid-round steering (busy modes) is explicitly deferred — see Task 3 limits.

**Tech Stack:** existing deps only (no new crates).

- No `engine/`/`eval/`/`llm/` changes. No new env knobs except `ROF_CREDENTIALS` (test override for the creds path) and the existing-knob reuse.
- HARD RULE: never execute `rof run`/`rof eval`/`rof chat` with cwd inside the repo. Demos in `/tmp`.

```rust
// src/tui/cmd.rs
//! Slash-command registry: one parser driving help, completion, and dispatch.

#[derive(Debug, PartialEq)]
pub enum Action {
    Quit, Help, Models, Context, Undo, Diff, Trace, Hotkeys,
    Model(String), Login(Option<String>), Logout(String),
    Attempts(u8), Rounds(u32), Thinking(String), Effort(String),
    Caps(usize, usize), Retry(Option<String>),
    Approve(String), Reject(String),
    Display(String), Busy(String),
    Unknown(String),
}

/// Parse composer input. `None` = plain goal text. Commands parse ONLY at
/// message start (claude rule); `/attempts 9` (out of 1-5) is Unknown, never
/// an error — the runner prints help instead of failing the session.
pub fn parse(input: &str) -> Option<Action> {
    let t = input.trim();
    if !t.starts_with('/') {
        return None;
    }
    let mut parts = t[1..].split_whitespace();
    let name = parts.next().unwrap_or("");
    let rest: Vec<&str> = parts.collect();
    let one = |i: usize| rest.get(i).map(|s| s.to_string());
    Some(match name {
        "quit" => Action::Quit,
        "help" => Action::Help,
        "models" => Action::Models,
        "context" => Action::Context,
        "undo" => Action::Undo,
        "diff" => Action::Diff,
        "trace" => Action::Trace,
        "hotkeys" => Action::Hotkeys,
        "model" => match one(0) {
            Some(m) => Action::Model(m),
            None => Action::Unknown("/model needs <provider>/<model-id>".into()),
        },
        "login" => Action::Login(one(0)),
        "logout" => match one(0) {
            Some(p) => Action::Logout(p),
            None => Action::Unknown("/logout needs <provider>".into()),
        },
        "attempts" => match one(0).and_then(|v| v.parse::<u8>().ok()).filter(|n| (1..=5).contains(n)) {
            Some(n) => Action::Attempts(n),
            None => Action::Unknown("/attempts takes 1-5".into()),
        },
        "rounds" => match one(0).and_then(|v| v.parse::<u32>().ok()).filter(|n| *n >= 1) {
            Some(n) => Action::Rounds(n),
            None => Action::Unknown("/rounds takes >= 1".into()),
        },
        "thinking" => match one(0) {
            Some(m) if ["off", "low", "on"].contains(&m.as_str()) => Action::Thinking(m),
            _ => Action::Unknown("/thinking takes off/low/on".into()),
        },
        "effort" => match one(0) {
            Some(m) if ["low", "medium", "high", "none"].contains(&m.as_str()) => Action::Effort(m),
            _ => Action::Unknown("/effort takes low/medium/high/none".into()),
        },
        "caps" => match (one(0).and_then(|v| v.parse::<usize>().ok()), one(1).and_then(|v| v.parse::<usize>().ok())) {
            (Some(a), Some(b)) => Action::Caps(a, b),
            _ => Action::Unknown("/caps takes <implementer> <reviewer>".into()),
        },
        "retry" => Action::Retry(one(0)),
        "approve" => match one(0) {
            Some(id) => Action::Approve(id),
            None => Action::Unknown("/approve needs <id>".into()),
        },
        "reject" => match one(0) {
            Some(id) => Action::Reject(id),
            None => Action::Unknown("/reject needs <id>".into()),
        },
        "display" => match one(0) {
            Some(m) if ["fullscreen", "regular"].contains(&m.as_str()) => Action::Display(m),
            _ => Action::Unknown("/display takes fullscreen/regular".into()),
        },
        "busy" => match one(0) {
            Some(m) if ["interrupt", "queue", "steer"].contains(&m.as_str()) => Action::Busy(m),
            _ => Action::Unknown("/busy takes interrupt/queue/steer".into()),
        },
        other => Action::Unknown(format!("/{other}")),
    })
}

pub fn help_text() -> String {
    "/quit /help /model <p/m> /models /login [provider] /logout <provider> /attempts 1-5 /rounds N /thinking off|low|on /effort low|medium|high|none /caps <i> <r> /retry [note] /approve|reject <id> /context /undo /diff /trace /display fullscreen|regular /busy interrupt|queue|steer /hotkeys".to_string()
}
```

```rust
// src/tui/auth.rs
//! Provider credentials: ~/.rof/credentials (0600), ROF_CREDENTIALS override
//! for tests. Env keys take precedence at call time (main.rs), so this store
//! is the interactive path to the same secrets, never the only path.

use std::collections::BTreeMap;
use std::path::PathBuf;

pub struct Store {
    path: PathBuf,
}

/// Resolve the store path. A test override wins so tests never touch home.
pub fn store() -> Store {
    let path = std::env::var("ROF_CREDENTIALS")
        .map(PathBuf::from)
        .unwrap_or_else(|_| {
            std::env::var("HOME")
                .map(|h| PathBuf::from(h).join(".rof/credentials"))
                .unwrap_or_else(|_| PathBuf::from(".rof-credentials"))
        });
    Store { path }
}

fn read_all(path: &PathBuf) -> BTreeMap<String, String> {
    std::fs::read_to_string(path)
        .ok()
        .and_then(|t| serde_json::from_str(&t).ok())
        .unwrap_or_default()
}

impl Store {
    /// Plugged-in provider names only — never keys.
    pub fn providers(&self) -> Vec<String> {
        read_all(&self.path).keys().cloned().collect()
    }

    /// Insert or overwrite a key. Creates parents, enforces 0600.
    pub fn save(&self, provider: &str, key: &str) -> anyhow::Result<()> {
        if let Some(parent) = self.path.parent() {
            std::fs::create_dir_all(parent)?;
        }
        let mut map = read_all(&self.path);
        map.insert(provider.to_string(), key.to_string());
        std::fs::write(&self.path, serde_json::to_string_pretty(&map)?)?;
        #[cfg(unix)]
        std::fs::set_permissions(&self.path, std::os::unix::fs::PermissionsExt::from_mode(0o600))?;
        Ok(())
    }

    /// Remove a provider. Returns false when it was not present.
    pub fn remove(&self, provider: &str) -> anyhow::Result<bool> {
        let mut map = read_all(&self.path);
        let hit = map.remove(provider).is_some();
        if hit {
            std::fs::write(&self.path, serde_json::to_string_pretty(&map)?)?;
        }
        Ok(hit)
    }
}
```

Hard limits (explicit — not placeholders, but scope walls):
- The loop runs one goal at a time on the main task: while it runs, composer Enter queues ONE pending goal (any further Enter replaces it — single slot, no list).
- Slash actions apply between goals only: `/attempts /rounds /thinking /effort /caps` set session-local env overrides via `std::env::set_var` before the next goal starts (same names the loop already reads at call time — zero new plumbing); `/model` + `/login` print "wires in Task 4" (explicit deferred message, exit path, not silent).
- `/undo` runs `tree.rollback()` equivalent is NOT available (tree lives per-task inside the loop) — print "per-task rollback is automatic; cross-goal undo lands with Plan C Task 4". Do not fake it.
- `q`/Esc/Ctrl-C while a goal runs sets a `stop_after_goal` flag (indicator line); second press exits immediately (blocking call is not interruptible — say so in the indicator).

Exact structure (write it fully — no sketch):

```rust
/// Live session: poll the shared trace, render at ~30fps, queue one goal.
/// Goal N+1 starts when goal N's run_loop future resolves. Slash actions
/// apply between goals via session-local env overrides (the loop reads the
/// same vars at call time, so no orchestrator changes).
pub fn run_live(trace: &crate::obs::TraceSink) -> anyhow::Result<()> {
    use crossterm::terminal::{disable_raw_mode, enable_raw_mode};
    use crossterm::ExecutableCommand;
    use std::time::Duration;
    enable_raw_mode()?;
    std::io::stdout().execute(EnterAlternateScreen)?;
    let out = run_live_inner(trace);
    disable_raw_mode()?;
    std::io::stdout().execute(LeaveAlternateScreen)?;
    out
}
```

`run_live_inner` owns `App`, a `shown: usize` cursor into `trace.events()`, a `pending: Option<String>` single goal slot, and the crossterm pump from `run_repl` (reuse its key handling: chars/backspace/enter/q-Esc-CtrlC). Each frame: `for ev in trace.events().skip(shown) { app.on_event(&ev); shown += 1; }`, draw, poll 33ms. Enter behavior: if a goal is running → store/replace `pending`; else → return `Goal(input)` to main (main runs it, then re-enters). Slash input → apply `Action` immediately for display-only ones (`Help/Models/Context/Trace/Hotkeys/Unknown` render into transcript), queue env overrides for knob ones, `Quit` exits. Since `run_loop` is async and blocking, `run.rs` exposes `pub enum LiveOut { Goal(String), Quit }` and main owns the goal loop:

```rust
/// Verify a key with one cheap call; return model ids. Unknown providers
/// error before touching the network so the test stays offline.
pub async fn verify(provider: &str, key: &str) -> Result<Vec<String>, String> {
    let base = match provider {
        "openrouter" => "https://openrouter.ai/api/v1",
        "go" => "https://opencode.ai/zen/go/v1",
        "atria" => "https://api.atria-asi.ai/v1",
        _ => return Err(format!("unknown provider '{provider}' (openrouter/go/atria)")),
    };
    let url = format!("{base}/models");
    let resp = reqwest::get(&url).await.map_err(|e| e.to_string())?;
    // Key validity is best-effort: some bases list models without auth.
    // Return the id list when parseable, else the status as context.
    let v: serde_json::Value = resp.json().await.map_err(|e| e.to_string())?;
    let ids = v.pointer("/data").and_then(|d| d.as_array())
        .map(|a| a.iter().filter_map(|m| m.pointer("/id").and_then(|i| i.as_str()).map(str::to_string)).collect())
        .unwrap_or_default();
    let _ = key;
    Ok(ids)
}
```

(reqwest 0.12 with json + rustls-tls is already a dependency per Cargo.toml — verify before writing; `reqwest::get` + `.json()` need no new features beyond `json`.)
