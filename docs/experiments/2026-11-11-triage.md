## How every column is derived

- **Row** = the directory holding `verifier-logs/verifier/` (rof native, in-container) or `verifier/` (harbor, in-container). 242 rows: 237 with `ctrf.json`, 5 with only `reward.txt`.
- **family** = `[metadata] category` in the frozen task `task.toml`.
- **estimand** = the report `provenance.estimand` when present; else the harbor job's `result.json` `stats.evals` key (`oracle__…` = the gold patch graded, `rof__…` = the RofAgent graded in the agent's own container); else `rof eval --agent --in-container` in the pilot driver; else `unknown`. Gold rows are listed but excluded from every count that speaks about model capability.
- **fidelity** = `post-fix` iff the row's own `binary_git_sha` carries **all six** 2026-11-06 workspace-fidelity commits (equivalently: `3874141` is an ancestor); `pre-fix` iff it carries fewer. The evidence cell states how many of the six that binary already contains. With no `binary_git_sha`, a run-artefact mtime strictly before the fix commit dates the row `pre-fix` (sound: the binary cannot contain a commit that did not exist); a later mtime stays `unknown` because the built tree is unrecorded. Directory mtimes are not used — `verifier-logs/` carries migration timestamps (2026-10-26) that disagree with the run.
- **halt** = the `RunEnd` outcome in the row's own `events.jsonl` (`Passed`→`done`, `Failed:tokens`→`tokens`, `Failed:steps`→`steps`, any other failure→`error`), `no_run_end` when the dump has no `RunEnd`; the report `halt_reason` is the fallback. **steps** = `MessageStart` count.
- **failing tests** = `results.tests[].name` with `status == failed` in `ctrf.json`, sorted. Recorded only; never used to pick a class.
- **class** = from the public `instruction.md` alone. `environment/infra` when an unsolved row banked no verifier verdict (`no_ctrf`/malformed ctrf, or `halt=error`); a solved row is never infra, because the reward stands whatever ended the agent loop. Otherwise `rerun-context/artefact-form` when the public statement names an artefact whose *form* is checkable (path/filename plus a literal structural fact, or a stated command), and `accuracy/correctness` when the stated acceptance is a computed result or a behaviour that no literal form test can decide. Harness tails (`Reasoning Effort:`, `Rules: all paths are relative…`, `COMPLETION CHECKLIST`) are stripped before the quote is taken.
